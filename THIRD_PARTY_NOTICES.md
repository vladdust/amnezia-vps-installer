# Сторонние исходники

Установочный архив содержит два исходных ZIP-файла, переданных владельцем сборки:

- [`s1riller/amnezia-server-kit`](https://github.com/s1riller/amnezia-server-kit), снимок `amnezia-server-kit-main.zip`;
- [`upe4d/tspublock`](https://github.com/upe4d/tspublock), снимок `tspublock-master.zip`.
- [`C24Be/AS_Network_List`](https://github.com/C24Be/AS_Network_List), сетевые списки, загружаемые модулем фильтра по запросу и обновляемые на сервере.

ZIP-файлы сохранены как входные снимки и проверяются по контрольным суммам. В предоставленных архивах отдельные файлы лицензии не обнаружены. Авторские права на исходные проекты остаются за их авторами; этот установщик не заявляет авторство или лицензию на сторонний код. Условия использования и актуальность проектов проверяйте у авторов.

Для `C24Be/AS_Network_List` указана лицензия BSD-2-Clause. Код и списки этого проекта не включены в установочный архив; модуль получает готовые списки напрямую и хранит серверную копию для последующего обновления при недоступности GitHub.
