# Сроки доступа и неактивные конфиги

Все действия модуля доступны через кнопки Telegram-бота.

- В меню «Клиенты» нажмите «➕ Новый клиент» и выберите обычный или временный доступ. После ввода имени для временного доступа выберите срок: 1, 7, 30, 90 или 365 дней. Бот выдаст конфиг и QR-код, как при создании обычного клиента.
- В «Клиенты» → «Доступы» можно посмотреть сроки и продлить доступ. Там же можно выбрать уже существующий постоянный ключ и назначить ему срок. После окончания срока клиент автоматически отключается, конфиг сохраняется.
- «Неактивные» показывает кандидатов для проверки. Отключение требует отдельного подтверждения, автоматического удаления нет. История наблюдения начинается после установки модуля; без известного рукопожатия кандидат появляется после 30 дней.
