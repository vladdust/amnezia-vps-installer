Управление администраторами
Модуль добавляет в главное меню Telegram-бота кнопку «Администраторы». Доступ к экрану есть только у уже зарегистрированных администраторов.
Чтобы добавить администратора, нажмите «Добавить администратора» и отправьте его числовой Telegram ID. Изменение сразу сохраняется в конфигурации бота. Новый администратор должен открыть диалог с ботом и нажать Start, чтобы начать им пользоваться.
В боте можно посмотреть текущий список администраторов. Добавить уже существующий ID повторно нельзя. Модуль не использует команды со слешем.
