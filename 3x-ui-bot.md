# Отдельный Telegram-бот для 3x-ui

Устанавливается рядом с уже работающей панелью 3x-ui и общается с ней через официальный API. Панель и другие VPN-компоненты установщик не меняет. Бот работает как отдельная systemd-служба и не связан с Amnezia-ботом.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/vladdust/amnezia-vps-installer/main/install-3xui-bot.sh | sudo bash
```

Установщик запросит URL панели (включая настроенный web-путь, если он есть; без `/panel/api`), API-токен из `Settings → Security → API Token`, токен Telegram-бота и Telegram ID администратора. Токены вводятся скрыто и сохраняются в `/etc/3x-ui-telegram-bot/config.json` с доступом только root и пользователю службы. Для удалённой панели нужен HTTPS; HTTP разрешён только для `localhost` и loopback-адресов.

После установки отправьте боту `/start`. Дальше все действия выполняются кнопками в личном чате:

- список и поиск клиентов, онлайн-статус, трафик и сроки;
- создание клиента на выбранном inbound со сроком 1, 7, 30, 90 или 365 дней либо без срока;
- получение ссылок подключения, которые сформировала сама панель;
- включение и отключение клиента;
- назначение срока или продление уже существующего клиента, а также снятие ограничения срока с подтверждением.

Новый клиент создаётся для inbound-протоколов, для которых API панели выдаёт текстовые ссылки: VMess, VLESS, Trojan, Shadowsocks, Hysteria и MTProto. Для остальных типов 3x-ui не предоставляет ссылку через endpoint клиента, поэтому бот не предлагает создавать для них доступ. Уже существующие клиенты отображаются в списке.

Для временного доступа бот передаёт срок в API 3x-ui. Истечение срока контролирует панель. Данные клиентов не хранятся в боте; для работы нужны доступ к API панели и Telegram. Установка требует GitHub и не устанавливает системные Python-пакеты: используется стандартная библиотека Python 3.

Журнал: `journalctl -u 3x-ui-telegram-bot -f`.
